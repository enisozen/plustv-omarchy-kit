# Plus TV

Smart TV and Media Hub launcher for Omarchy featuring widescreen cover cards for installed streaming and media platforms (Digiturk beIN CONNECT, Digiturk, Turkcell TV+, Apple TV+, Amazon Prime Video, Netflix, YouTube, Google Chrome, Apple Music, GeForce NOW).

## Shortcuts

| Key | Action |
|-----|--------|
| `←` `→` `↑` `↓` | Navigate media cover cards |
| `Enter` / `Space` | Launch selected application |
| `1` – `9` | Quick launch platform 1 – 9 |
| `Tab` / `Shift+Tab` | Cycle category tabs |
| `F` | Toggle fullscreen |
| `?` | Toggle shortcuts help |
| `Q` | Quit Plus TV |
